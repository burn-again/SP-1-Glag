GK1

Every slider changes the Kit as it plays (the ranges go well past the firmware's, so things can get loud and strange: Reset sliders brings them back), in the firmware's own engine. When it sounds right, copy the code and send it to me: it lists only what you changed (GK1;K_DECAY=1.4;…), plus what you were listening to, and I'll write those values into the firmware. Blue values differ from the firmware's. The channel controls above (Activity, Tone, Length, Register, Character, Macro) are the piece's own, here for listening. They go into the code as context, not as changes.

Step pattern

Click a step: on, then accent, then off. While it plays, the Kit plays only this, in place of its own pattern and groove, at the piece's tempo. The feel rules (press, long, hat accents), the rotation and the colour still apply. Accents are louder; for a long-ringing accent, raise Feel · Accent length.
